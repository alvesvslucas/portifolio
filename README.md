# Portfólio | Lucas Alves

Página pessoal de apresentação profissional e projetos de Lucas Alves, desenvolvida para a web.

## Sobre o projeto

O portfólio reúne informações sobre o desenvolvedor, trabalhos e formas de contato. A página utiliza HTML e CSS e organiza o conteúdo em seções como início, sobre, portfólio e contato.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como visualizar

1. Clone o repositório:

   ```bash
   git clone https://github.com/alvesvslucas/portifolio.git
   ```

2. Abra a pasta do projeto e execute o arquivo `index.html` no navegador. Também é possível usar um servidor local, como a extensão Live Server do VS Code.

## Estrutura principal

- `index.html` — página principal
- `css/` — estilos
- `assets/` — imagens e outros recursos visuais
